Document_QA_RAG_Assistant/README.md
Includes application code, RAG pipeline, dependencies, environment template, and README documentation.

What's included?
- PDF/TXT document loading using LangChain.
- Text chunking using RecursiveCharacterTextSplitter.
- Vector embeddings using Sentence Transformers.
- Vector storage and retrieval using ChromaDB.
- AI question answering using Google Gemini.
- Source references showing document filenames and PDF page numbers.
- Streamlit UI for uploading documents and asking questions.
- .env.example, .gitignore, requirements.txt, and setup instructions.
